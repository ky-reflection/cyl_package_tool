更新 Cytus II → Cytus I 转换器的 BPM 选项、帮助说明和 Windows 渲染后端。

## 更新内容

- 合入 [PR #1](https://github.com/ky-reflection/cyl_package_tool/pull/1)：新增可选的 tempo 脉动 BPM 算法。默认关闭时使用 `240 / PAGE_SIZE`，勾选后使用 `120,000,000 / tempo`（音乐 BPM × 2），不改变页长或音符时间。
- GUI 保持简洁：选择文件、设置 BPM 选项，然后点击 **Convert**。转换完成或发生错误时显示状态提示。
- 右上角新增紧凑的问号按钮。悬停预览转换约定，点击后保持打开；再次点击、点击外部或按 Esc 收起。
- 帮助按支持的谱面、时序与 BPM、输出分区，并列出页长、tempo、音符和偏移处理规则。
- 底部新增版权信息和 GitHub 仓库链接。
- Windows GUI 切换到 wgpu / Direct3D 12，并启用垂直同步，以处理原 OpenGL 后端交互时文字闪烁的问题。
- 改善文件读取、无效输入和保存错误的处理；支持带 UTF-8 BOM 的 JSON。

## 下载与使用

- **c2to1_converter-windows-x86_64.exe**：Windows x86_64 图形界面转换器，需要支持 Direct3D 12 的图形环境。
- **chart_viewer-windows-x86_64.exe**：Windows x86_64 命令行谱面预览工具。
- **SHA256SUMS.txt**：两个程序的 SHA-256 校验值。

转换器读取 Cytus II JSON（`.json` 或 `.txt`），输出到源文件旁的 `原文件名_converted.txt`；重复转换会覆盖同名输出。GUI 不要求 `#DEFINE CYTUS1` 标记。完整转换限制可在右上角帮助中查看。
